# 卷材续卷时的实际刀口与裁片追踪

fixtures/equipment.json 登记本地试验台设备和业务资料。fixtures/shift.ndjson 是合成班次消息，消息中的实物编号只用于演练。无需连接现场控制器。

## 班次资料

检测端和裁切端都按行进方向输出各自的毫米读点。thread 的 segment 是一次重新穿膜后的行程段，mark 只有在同一段且两端都识别同一标点时才有两端共见证据。slip_bound 约束两标点间两端映射可偏移的毫米范围；设备方向一致，兼容偏移在标点约束下保留。splice 标记将同段的材料分为左、右两卷。crease 消息给出检测端的纵向受影响区域。边料长度在卷宽两侧分别扣除，两侧都按订单规定。缺陷留量是纵向最短容许间隔。
ack_cut 的 committed 为真时该次落刀已过可撤回点，记录中的 interval_mm 是设备承诺区间。blade 的 span_mm 才是成品的实际边界。cut 号在每次穿膜段内重用，装托和实际取料凭证按实件登记。supersedes 指向折痕旧记录。

## 读取与回放

使用 Python 3.11 或更新版本，依赖均为标准库。在仓库根目录执行 `python -m unittest -v` 检查资料引用、两段读取及设备回环重连。执行 `python wire.py inspect` 查看当前输入涉及的设备和消息数。`python wire.py serve` 在 127.0.0.1:9040 提供本机回放，可用 --port 改端口和 --capture 指定外发消息记录。回放入口用 --trace 指定另一份兼容的班次文件，参数放在动作名之前。

每行 UTF-8 JSON 含 offset、peer、kind、body。offset 自 0 起连续递增，表示回放接收顺序。设备正文保留自己的观测时刻、动作号或参考读点，可能晚到或重传。行偏移可用于重新接续读取。

回放端接受逐行 JSON 请求。`read` 的请求字段是 op、from、limit，回复中的 events 是对应的连续消息片段。读取超出已有范围时返回空数组。`write` 的请求带 message，其内有 peer 和 body。工具将外发信封原样记到捕获文件，返回 recorded。这个回执来自本地记录器，设备的接收、读回及动作来自各自的设备消息。每次连接可执行多条请求。
